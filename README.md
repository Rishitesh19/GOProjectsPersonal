# Go Projects Personal

Small, practical projects built while learning Go.

| Day | Project | What it does |
| --- | --- | --- |
| [Day 1](Day1/) | Send to Mac | Receive browser uploads without exposing files on your Mac. |
| [Day 2](Day2/) | Tiny Transformer | Train a character-level Transformer from scratch using Go and parallel attention heads. |
| [Day 3](Day3/) | Simulated TCP/IPv4 | Encode packets, establish a connection, and retransmit lost data over an in-memory network. |
| [Day 4](Day4/) | Float64 storage | Encode IEEE 754 fields, save eight bytes, and reconstruct the number using arithmetic. |

Each project includes its own instructions and Go module. See [LICENSE](LICENSE) for the repository license.
